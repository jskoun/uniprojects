# Ship Drawings Digitizer

### From main page:

>The provided script was used during my internship to provide a quick way to digitize ship drawings (lines plan). It works in conjuction with [WebPlotDigitizer](https://github.com/automeris-io/WebPlotDigitizer) (a thanks is in order for the creators and maintainers of this software as it has proven to be an amazing tool throughout my studies). Given a lines plan of a marine craft, the Naval Architect can then select points using different coordinate systems for each curve, and then export the data as a JSON file. This file is then parsed by the script, which saves the ship's form and can either export it to a NAPA (naval architecture sofware) readable format, or plot it directly in 3D to easily assess any issues.
